## Como publicar no GitHub Pages

1. Crie um repositório novo no GitHub (pode ser público), por exemplo `portfolio`.
2. Suba os arquivos desta pasta (`index.html` e este `README.md`) para o repositório.
   - Pode ser pelo site do GitHub: "Add file" → "Upload files" → arraste os arquivos → "Commit changes".
3. No repositório, vá em **Settings** → **Pages** (menu lateral esquerdo).
4. Em "Build and deployment" → "Source", selecione **Deploy from a branch**.
5. Em "Branch", selecione `main` (ou `master`) e pasta `/ (root)`. Clique em **Save**.
6. Aguarde 1–2 minutos. O GitHub vai mostrar o link do site, algo como:
   `https://SEU-USUARIO.github.io/portfolio/`
7. Esse é o link que você usa no LinkedIn.

## Atualizações futuras

Sempre que quiser atualizar o site, basta subir uma nova versão do `index.html`
substituindo o arquivo no repositório (o link continua o mesmo).
